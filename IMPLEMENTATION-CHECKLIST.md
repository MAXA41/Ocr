## 🗄️ Структура базы данных:

### Таблицы Supabase:
```
product_categories (создана)
├─ id UUID PRIMARY KEY
├─ name_uk TEXT - название категории на украинском
├─ fields JSONB - структура полей формы
├─ variant_options JSONB - опции для вариантов
├─ is_active BOOLEAN
└─ display_order INTEGER

product_catalog_items (существует + обновлена)
├─ id UUID PRIMARY KEY
├─ name TEXT
├─ description TEXT
├─ category UUID (FK product_categories)
├─ price INTEGER
├─ is_available BOOLEAN
└─ extra_data JSONB - дополнительные поля

product_variants (создана)
├─ id UUID PRIMARY KEY
├─ product_id UUID (FK product_catalog_items)
├─ variant_values JSONB - {"color": "#000000"} или {"size": "M"}
├─ image_url TEXT
├─ price INTEGER
├─ stock_quantity INTEGER
└─ is_active BOOLEAN

variant_definitions (создана)
├─ id UUID PRIMARY KEY
├─ variant_type TEXT - "color", "size"
├─ variant_value TEXT
└─ category_id UUID (FK product_categories)

audit_logs (существует)
├─ Все изменения товаров логируются автоматически
└─ Отправляются уведомления в Telegram
```

## 🚀 Как использовать систему:

### 1️⃣ Добавление товара через веб (админ-панель):

```bash
1. Откройте: http://localhost:5173/admin-product-form.html
2. Выберите категорию (например, "Аксесуари")
3. Заполните поля:
   - Назва: "Кофемашина Delonghi"
   - Опис: "Автоматична кофемашина..."
   - Бренд: "Delonghi"
   - Матеріал: "Пластик"
4. Добавьте варианты (цвета):
   - Вариант 1: Красный (#FF0000) - Цена 5000 грн - Фото
   - Вариант 2: Черный (#000000) - Цена 5000 грн - Фото
   - Вариант 3: Серебро (#C0C0C0) - Цена 5500 грн - Фото
5. Нажмите "Зберегти товар"
6. ✅ Товар появляется в Supabase и на сайте
```

### 2️⃣ Добавление товара через Telegram:

```bash
1. Откройте Telegram → @O_Roasters_Bot
2. Отправьте /add
3. Выберите категорию кнопкой (например, "Аксесуари")
4. Заполните поля пошагово:
   - Назва товару: "Кофемолка ручна"
   - Опис: "Жерновова кофемолка..."
   - Ціна: "1500"
   - Бренд: "Baratza"
   - Матеріал: "Нержавіющая сталь"
5. ✅ Получаете подтверждение с ID товара
6. Товар уже видно на сайте
```

### 3️⃣ Просмотр вариантов на сайте:

```bash
1. Откройте товар с вариантами на сайте
2. Видите кнопки выбора:
   - Для цветов: [■ Red] [■ Black] [■ Silver]
   - Для размеров: [XS] [S] [M] [L] [XL] [XXL]
3. Нажимаете на вариант:
   - ✅ Изображение меняется
   - ✅ Цена обновляется
   - ✅ Кнопка подсвечена
4. Добавляете в корзину:
   - ✅ Выбранный вариант сохранен
```

                  → getCategories()
                  → handleCategorySelection()
                  → collectUserInput()
                  → saveProductFromBot()
                  → product_catalog_items
                  → audit_logs (автоматически)
                  → Уведомление в Telegram
                  → Сайт обновляет товар
