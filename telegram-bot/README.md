# 🤖 Telegram Bot - Админ-панель для товаров

Полнофункциональный Telegram бот для управления товарами каталога с помощью AI.

## ✨ Возможности

- ✅ **Добавление товаров** - AI анализирует описание и структурирует данные
- ✅ **Редактирование товаров** - Изменение названия, описания, доступности
- ✅ **Управление ценами** - Добавление и изменение цен с SKU
- ✅ **Удаление товаров** - С подтверждением
- ✅ **Просмотр каталога** - Список всех товаров
- ✅ **Поиск** - Поиск по названию и описанию
- ✅ **Статистика** - Информация о товарах
- ✅ **AI Помощник** - Использует Ollama для анализа текста

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd telegram-bot
npm install
```

### 2. Проверка .env файла

Файл `.env` уже создан с данными:
```
TELEGRAM_BOT_TOKEN=9179345540:AAFkEwDYsBIbCFwrSFRairVYOW0J3Rm8uH0
SUPABASE_URL=https://sxxlotfbcblnjgcvxaqe.supabase.co
SUPABASE_ANON_KEY=...
```

### 3. Убедитесь, что Ollama запущена

```bash
ollama serve
```

Модель должна быть загружена:
```bash
ollama pull qwen2.5-coder:1.5b
```

### 4. Запуск бота

```bash
npm start
```

**Вывод должен быть:**
```
🤖 Бот запущен и готов к работе!
```

## 📱 Использование

### В Telegram найдите вашего бота и нажмите `/start`

**Доступные команды:**

| Команда | Что делает |
|---------|-----------|
| `/start` | Показывает приветствие и меню |
| `/add` | Добавить новый товар (AI поможет) |
| `/list` | Показать все товары |
| `/edit` | Редактировать товар |
| `/delete` | Удалить товар |
| `/search` | Поиск товара |
| `/stats` | Статистика каталога |

### Примеры использования

#### Добавление товара

1. Нажимаем `/add` или кнопку "➕ Добавить товар"
2. Пишем описание: *"Espresso Blend 250g, премиум качество, из Эфиопии"*
3. AI автоматически анализирует и структурирует:
   - Название: Espresso Blend
   - Описание: 250g, премиум качество
   - Категория: кофе
4. Подтверждаем или редактируем
5. Добавляем цену: *150*
6. Добавляем SKU: *ESP-250*
7. Товар сохранен ✅

#### Редактирование товара

1. `/edit` → выбрать товар
2. Выбираем что менять:
   - 📝 Описание
   - 💰 Цена
   - ✅ Доступность
3. Вводим новое значение
4. Товар обновлен ✅

#### Удаление товара

1. `/delete` → выбрать товар
2. Подтверждаем удаление
3. Товар удален ✅

## 🧠 Как работает AI

Бот использует **Ollama** и модель **Qwen 2.5 Coder 1.5B** локально.

### Что AI делает:

1. **Анализирует текст** - Понимает что это за товар
2. **Структурирует данные** - Выделяет название, описание, категорию
3. **Генерирует теги** - Автоматически создает релевантные теги
4. **Работает локально** - Никакие данные не уходят в облако ✅

### Пример анализа

Вы пишите:
```
Espresso 250g, Premium качество, из Эфиопии, крупный помол, для турки
```

AI разбирает:
```json
{
  "name": "Espresso 250g Premium",
  "description": "Крупный помол из Эфиопии, премиум качество",
  "category": "кофе",
  "tags": ["espresso", "250g", "premium", "эфиопия"]
}
```

## 📊 Структура данных

### Таблица: product_catalog_items
```
- id (UUID) - Уникальный ID
- name - Название товара
- description - Описание
- is_available - Доступен ли товар
- created_at - Когда создан
- updated_at - Когда обновлен
```

### Таблица: product_price_overrides
```
- id (UUID)
- product_id - Ссылка на товар
- price - Цена в гривнях
- sku - Артикул
- created_at
- updated_at
```

## 🔄 Интеграция с системой логирования

Все действия автоматически логируются:

1. **audit_logs** - Запись каждого изменения
2. **Telegram уведомления** - Админ группе отправляется уведомление
3. **История** - Полная история всех действий

**Пример логирования:**
```
✏️ Оновлено
📊 Продукт
📝 Espresso 250g
⏰ 02.11.2026, 05:45
```

## 🐛 Решение проблем

### "Cannot connect to Ollama"
- Убедитесь что Ollama запущена: `ollama serve`
- Проверьте что модель загружена: `ollama list`

### "Bot token invalid"
- Проверьте TELEGRAM_BOT_TOKEN в .env файле
- Убедитесь что бот создан в BotFather

### "Cannot connect to Supabase"
- Проверьте SUPABASE_URL и SUPABASE_ANON_KEY
- Убедитесь что в Supabase есть таблицы product_catalog_items и product_price_overrides

### AI не работает / не анализирует
- Ollama должна быть запущена
- Модель должна быть загружена: `ollama pull qwen2.5-coder:1.5b`
- Попробуйте перезагрузить бот
