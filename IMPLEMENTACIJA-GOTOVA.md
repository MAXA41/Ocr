## 🚀 Як запустити

### 1️⃣ Виконайте SQL міграцію

Перейдіть в [Supabase SQL Editor](https://supabase.com/dashboard) і виконайте:

```sql
alter table public.product_price_overrides
  add column if not exists color_variants jsonb default '[]'::jsonb;

comment on column public.product_price_overrides.color_variants is 
'Array of color variant objects: [{name: "Black", image_url: "https://...", description: "Чорна обпалювання"}, ...]';
```

### 2️⃣ Оновіть код

Переконайтеся, що файли оновлені:
```bash
git pull origin main  # або manual sync
```

### 3️⃣ Перезавантажте браузер

```
Ctrl+Shift+Delete  # Очистити кеш
Ctrl+Shift+R       # Жорсткі оновлення
```

### 4️⃣ Тестуйте

1. Залогіньтеся на [ocr.com.ua/account.html](https://ocr.com.ua/account.html)
2. Розкрийте карточку товару
3. Знайдіть розділ "Варіанти кольорів"
4. Натисніть "+ Додати колір"
5. Заповніть тестові дані
6. Натисніть "Зберегти"

```javascript
  name: "Темна обпалювання",

    { name: "Чорна", description: "Темна", image_url: "..." },
    { name: "Світла", description: "Яскрава", image_url: "..." }
  ]
};

// На сторінці товару:

  // Рендерити вкладки, слайдер або інший UI для вибору кольору
}
```
