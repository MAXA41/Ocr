## 🎯 ЧТО РОБИТЬ АДМІН ПАНЕЛЬ?

Адмін панель дозволяє:
- ✅ Додавати нові товари (кави, фільтри, аксесуари тощо)
- ✅ Встановлювати базову ціну
- ✅ Додавати варіанти товарів (кольори, розміри тощо)
- ✅ Встановлювати ціни для кожного варіанту
- ✅ Контролювати кількість товару на складі

## 📝 ПОКРОКОВИЙ ГАЙД: ЯК ДОДАТИ ТОВАР

### ШАГ 1️⃣: Виберіть категорію товару

**Натисніть на поле "📂 Категорія Товару"** і виберіть одну з доступних категорій:

```
🔽 -- Виберіть категорію --
   ☕ Кава
   📊 Еспресо
   ⏰ Фільтри
   🛠️ Аксесуари
   👕 Мерч
   🎁 Декаф
```

**Приклад:** Якщо ви додаєте кофемашину, виберіть **"Аксесуари"**

⚠️ **ВАЖЛИВО:** Після вибору категорії форма автоматично змінить свій вигляд і покажет спеціальні поля для цієї категорії!

---

### ШАГ 2️⃣: Введіть назву товару

**Поле "Назва Товару"** - це те, що будуть бачити клієнти на сайті.

✅ **Примери хороших назв:**
- "Кофемашина DeLonghi Dedica Red"
- "Ручна кофемолка Comandante C40"
- "Фільтр V60 Hario Прозорий"
- "Еспресо Темний Обжарок 1 кг"

❌ **Плохие примеры:**
- "товар"
- "кофе"
- "qqq123" (неправильна назва)

---

### ШАГ 3️⃣: Додайте детальний опис

**Поле "Опис"** - це місце для повного опису того, що покупець отримає.

✅ **Хороший опис містить:**
- Матеріали (нержавіюча сталь, кераміка, скло)
- Розміри / Вихід (на скільки порцій)
- Країна виробництва
- Особливості (регульована температура, автоматична система)

**Приклад:**
```
Кофемашина DeLonghi Dedica Red - компактна еспресо-машина 
для дому. Об'єм бака 1 л, система автоматичного вспінювання 
молока, потужність 1300 Вт. Вироблена в Італії. 
Идеальна для приготування еспресо, капучино, латте.
```

---

### ШАГ 4️⃣: Встановіть базову ціну

**Поле "Базова Ціна (грн)"** - це основна ціна товару.

```
💵 Введіть число (без "грн", без пробілів)
Приклади: 1500, 2999, 15000
```

⚠️ **ВАЖЛИВО:** Це мінімальна ціна. Якщо у вас будуть варіанти (кольори, розміри), кожний варіант може мати свою ціну!

---

### ШАГ 5️⃣: Заповніть спеціальні поля категорії

**Після вибору категорії** форма автоматично покажет додаткові поля. Вони різні для кожної категорії:

#### 🔹 Для категорії **"Аксесуари"** (кофемолки, кофемашини):
- **Тип аксесуара** (обов'язково)
  - Кофемолка
  - Кофемашина
  - Чайник
  - Лійка для кави
  - Інше

- **Бренд** (обов'язково) - назва виробника
  - Hario
  - Comandante
  - DeLonghi
  - Breville
  - Інше

- **Матеріал** (опційно)
  - Нержавіюча сталь
  - Кераміка
  - Пластик
  - Дерево
  - Граніт
  - Скло

- **Розміри** (опційно) - L x W x H у см

---

#### 🔹 Для категорії **"Еспресо"** (кава для еспресо):
- **Вага** (обов'язково) - вага упаковки (грам)
  - 250g
  - 500g
  - 1000g

- **Походження** (обов'язково) - країна, з якої привезена кава
  - Бразилія
  - Колумбія
  - Ефіопія
  - Гватемала
  - Індонезія
  - Інше

- **Смакові ноти** (опційно) - профіль смаку
  - Шоколад
  - Горіхи
  - Ягоди
  - Фрукти
  - Пісок
  - Квіти

- **Рівень обжарки** (обов'язково)
  - Світлий
  - Середній
  - Темний

---

#### 🔹 Для категорії **"Мерч"** (футболки, кружки):
- **Матеріал** (обов'язково)
  - Бавовна 100%
  - Полотно
  - Кераміка
  - Інше

- **Розмір** (опційно)
  - XS, S, M, L, XL, XXL (для одягу)
  - Стандарт (для кружок, аксесуарів)

---

### ШАГ 6️⃣: (ОПЦІОНАЛЬНО) Додайте варіанти товару

**Якщо ваш товар має варіанти** (різні кольори, розміри) - натисніть **"+ Додати Варіант"**

**Приклад:** Кофемашина доступна в 3 кольорах:
1. Red (червона) - 2500 грн
2. Black (чорна) - 2500 грн
3. Silver (срібна) - 2700 грн

#### 🎨 Додавання варіанту:

1. **Натисніть "+ Додати Варіант"**
2. **Заповніть варіант:**
   - Виберіть колір (якщо варіант - колір)
   - Виберіть розмір (якщо варіант - розмір)
   - **Ціна варіанту** - якщо варіант коштує по-іншому від базової ціни
   - **Кількість на складі** - скільки одиниць цього варіанту у наявності

3. **Натисніть "🗑️ Видалити"** щоб видалити варіант

**Приклад варіанту кофемашини Red:**
```
Колір: Red (червона)
Ціна: 2500
Кількість на складі: 5
```

**Приклад варіанту Silver (більш дорога):**
```
Колір: Silver
Ціна: 2700 (більше на 200 грн)
Кількість на складі: 3
```

---

### ШАГ 7️⃣: Натисніть "✅ Додати Товар"

Коли все заповнено - натисніть велику кнопку **"✅ Додати Товар"**.

**Що відбудеться:**
- ⏳ Форма покажет статус "Обробка..."
- ✅ Товар збереться в базу даних
- 📢 З'явиться повідомлення **"Успіх! Товар додано!"**
- 🆔 Вам покажет ID товару для подальшого запиту
- 🔄 Форма очиститься

**Товар тепер видимий:**
- На сайті (у каталозі)
- В Telegram ботові (команда `/list`)
- В адмін панелі

## ❌ ЧАСТІ ПОМИЛКИ

### ❌ Помилка 1: Виникає помилка "Помилка завантаження категорій"
**Причина:** Сервер не запущений або низька швидкість інтернету

**Рішення:**
- Перезавантажте сторінку (F5)
- Переконайтеся що `npm run dev` працює
- Перевірте інтернет-з'єднання

---

### ❌ Помилка 2: Після натискання "Додати товар" нічого не відбувається
**Причина:** Суповий ключ API закінчився або невалідний

**Рішення:**
- Перевірте консоль браузера (F12 → Console)
- Проверьте що SUPABASE_KEY в коді не порожня

---

### ❌ Помилка 3: Форма не показує варіанти
**Причина:** Ця категорія не має варіантів

**Рішення:**
- Вибрана категорія не підтримує варіанти
- Вибраите іншу категорію (наприклад "Аксесуари" з кольорами)

---

### ❌ Помилка 4: Ціна не зберігається
**Причина:** Введено буквами або з "грн"

**Рішення:**
```
❌ Неправильно: "1500 грн", "one thousand five hundred"
✅ Правильно: 1500
```

## 📱 ПЕРЕГЛЯД ДОДАНИХ ТОВАРІВ

### На сайті:
1. Відкрийте http://localhost:5173/
2. Натисніть на категорію
3. Побачите новий товар там

### В Telegram ботові:
1. Напишіть боту `/list`
2. Бот покажет всі товари що були додані

### В Supabase (база даних):
1. Відкрийте https://supabase.com/dashboard
2. Перейдіть до проекту **Ocr**
3. Таблиця `product_catalog_items` - всі товари
4. Таблиця `product_variants` - всі варіанти

---

## 🎓 НАВПАКИ - ВИДАЛЕННЯ ТОВАРУ

**Щоб видалити товар:**

### Через Supabase:
1. Відкрийте https://supabase.com/dashboard/project/sxxlotfbcblnjgcvxaqe
2. Перейдіть до таблиці `product_catalog_items`
3. Знайдіть товар
4. Натисніть на рядок
5. Натисніть "Delete"

### Через SQL командой:
```sql
DELETE FROM product_catalog_items WHERE id = 'товар-id';
```

⚠️ **ВАЖЛИВО:** Видалення товару також видалить все його варіанти!
