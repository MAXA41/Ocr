# 🚀 АДМІН ПАНЕЛЬ - ШВИДКИЙ СТАРТ

## 📍 ЛІНК НА ПАНЕЛЬ

**Локально:** http://localhost:5173/admin-product-form.html  
**На сайті:** https://odesa-coffee-roasters.com/admin-product-form.html

---

## ⚡ 5 КРОКІВ ДО ДОДАВАННЯ ТОВАРУ

### 1️⃣ Выберіть категорію
```
🔽 Категорія → Аксесуари / Еспресо / Фільтри / Мерч / Декаф
```

### 2️⃣ Введіть назву товару
```
📝 DeLonghi Dedica Coffee Machine
```

### 3️⃣ Додайте опис
```
📋 Компактна еспресо-машина з 1 л баком...
```

### 4️⃣ Встановіть ціну
```
💵 2500
```

### 5️⃣ Натисніть "✅ Додати Товар"
```
✅ Готово! Товар додано на сайт
```

---

## 🎨 ДОДАВАННЯ ВАРІАНТІВ (кольори, розміри)

```
+ Додати Варіант → Виберіть колір → Введіть ціну → Кількість
```

**Приклад:**
- Red → 2500 грн → 5 шт
- Black → 2500 грн → 3 шт  
- Silver → 2700 грн → 2 шт

## ✅ РЕКОМЕНДАЦІЯ ПЕРЕД ЗАПУСКОМ

```bash
# 1. Запустіть локальний сервер
npm run dev

# 2. Відкрийте адмін панель
http://localhost:5173/admin-product-form.html

# 3. Тестуйте додавання товарів
# 4. Перегляньте результат на сайті
# 5. Коли все готово - push на GitHub
```

## 🐛 ЯКЩО ЩОС НЕ ПРАЦЮЄ

| Проблема | Рішення |
|----------|---------|
| Категорії не завантажуються | Перезагрузіть сторінку (F5) |
| Товар не зберігається | Перевірте консоль (F12 → Console) |
| Варіанти не показуються | Виберіть категорію що має варіанти |
| Помилка "Помилка при збереженні" | Перевірте що SUPABASE_KEY актуальна |

## 💡 ПЕРЕВІРЕНА МУДРІСТЬ

✅ **Робіть:**
- Давайте англійські назви товарам
