## 🛡️ КАК ЭТО РАБОТАЕТ?

### При входе на адмін панель:
1. **Показується екран входу** 🔐
2. **Введіть один з паролів вверху** (будь-який из 5)
3. **Натисніть "Увійти"**
4. ✅ **Отримаєте доступ до форми**

### Пароль зберігається:
- 💾 **У sessionStorage** браузера
- 🔒 **Тільки для цієї сесії** (не зберігається на жорсткому диску)
- 🚪 **При закритті вкладки** - пароль видаляється

### Якщо ввести неправильний пароль:
- ❌ Показується помилка "Неправильний пароль!"
- 🔄 Поле очищується
- 🔐 Форма залишається закритою

## 💡 ДОДАТКОВІ OPЦІЇ

### Якщо забули пароль:
1. Відкрийте `admin-product-form.html` в редакторі
2. Знайдіть `VALID_PASSWORDS`
3. Скопіюйте один з паролів
4. Вставте в форму входу

### Якщо хочете видалити захист:
1. Видаліть весь код під коментарем `// Valid passwords`
2. Видаліть HTML під коментарем `<!-- Login Screen -->`
3. Видаліть CSS під коментарем `/* Login Screen Styles */`
