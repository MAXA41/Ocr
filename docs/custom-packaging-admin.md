# Управління кастомними варіантами упаковки товарів

## Огляд

Адміністратор каталогу тепер має можливість додавати додаткові варіанти упаковки для кожного товару:

- **Мерч** (за штуку, без міри) — для товарів без вимірювання (чашки, меч тощо)
- **Штучно** (за пакетик/штуку) — для дріп-пакетів, фільтр-пакетів тощо
- **Кастомна міра** — для довільної одиниці виміру, яку вводить адміністратор (наприклад, 50г, 100g, 500мл)

## Як додати кастомні варіанти

### 1. Відкрийте панель адміністратора каталогу

Увійдіть в [особистий кабінет](https://oroasters.com.ua/account.html) та перейдіть до секції "Операційний каталог".

### 2. Виберіть товар для редагування

На карточці товару знайдіть секцію **"Додаткові варіанти упаковки"**.

### 3. Заповніть необхідні поля

У цій секції відобразяться чотири поля:

#### Ціна за штуку (мерч, без міри)
- Введіть ціну за одиницю товару, коли він продається без вимірювання
- Приклад: чашка — 45 грн, товар для мерчу — 50 грн

#### Ціна за штуку (пакетик, штука)
- Введіть ціну за один пакетик/штуку для товарів типу дріпів чи фільтр-пакетів
- Приклад: дріп-пакет — 65 грн

#### Кастомна міра (текст)
- Введіть довільну одиницю виміру, яку ви хочете додати
- Приклади: `50g`, `100g`, `500ml`, `250мл`, `1 шт`

#### Ціна за кастомну міру, грн
- Введіть ціну для цієї кастомної міри
- Поле активується тільки якщо заповнено поле "Кастомна міра"

### 4. Збережіть зміни

Натисніть кнопку "Зберегти зміни" внизу карточки товару. Зміни будуть видимі в онлайн-каталозі протягом кількох секунд.

## Як це працює на фронтенді

Коли клієнт відкриває сторінку товару або дивиться каталог:

1. Якщо товар має кастомні варіанти упаковки, вони відобразяться в селекторі об'єму
2. Клієнт зможе вибрати будь-який з доступних варіантів (250г, 1кг, штука, мерч тощо)
3. Ціна автоматично оновиться при виборі варіанта
4. Вибрана упаковка попиниться в замовленні з правильною ціною

## Приклади конфігурацій

### Для дріп-пакетів
```
Ціна за штуку (мерч): [порожньо]
Ціна за штуку (пакетик): 45
Кастомна міра: [порожньо]
Ціна за кастомну міру: [порожньо]
```

### Для мерчу (чашок, маєток)
```
Ціна за штуку (мерч): 50
Ціна за штуку (пакетик): [порожньо]
Кастомна міра: [порожньо]
Ціна за кастомну міру: [порожньо]
```

### Для проб/семплів
```
Ціна за штуку (мерч): [порожньо]
Ціна за штуку (пакетик): [порожньо]
Кастомна міра: 30g
Ціна за кастомну міру: 80
```

### Для комбованого товару (кава + мерч)
```
Ціна за штуку (мерч): 45 [для чашки]
Ціна за штуку (пакетик): [порожньо]
Кастомна міра: 100g
Ціна за кастомну міру: 150 [для пакетика 100г]
```

## Технічні деталі

### Збереження в Supabase

Кастомні варіанти зберігаються в колонці `custom_variants` таблиці `product_price_overrides` як JSON масив:

```json
[
  {"unit": "merch", "price": 45},
  {"unit": "piece", "price": 65},
  {"unit": "50g", "price": 150}
]
```

### API представлення

Коли фронтенд отримує дані товару через Supabase, вони розпаковуються в поле `customVariants`:

```javascript
{
  id: "product-id",
  name: "Product Name",
  price: 1155,
  volumePrices: { "250g": 320, "1kg": 1130 },
  customVariants: [
    { unit: "merch", price: 45 },
    { unit: "piece", price: 65 }
  ]
}
```

## Рішення проблем

### Варіанти не з'являються на сайті
- Переконайтеся, що ви натиснули "Зберегти зміни"
- Оновіть сторінку браузера (Ctrl+F5)
- Перевірте, що в Supabase колона `custom_variants` містить валідний JSON

### Неправильна ціна відображається
- Переконайтеся, що поле ціни заповнено числом без літер
- Перевірте формат: ціни вводяться в гривнях без знаку валюти

### Кастомна міра не зберігається
- Заповніть обидва поля: "Кастомна міра" та "Ціна за кастомну міру"
- Натисніть "Зберегти зміни"
