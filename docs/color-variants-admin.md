# Управління варіантами кольорів товарів

## Розташування в інтерфейсі

У панелі управління каталогом кожна карточка товару містить новий розділ **"Варіанти кольорів"** після розділу "Додаткові варіанти упаковки".

## Як додати варіант кольору

1. Розкрийте карточку товару натисканням на неї
2. Прокрутіть вниз до розділу **"Варіанти кольорів"**
3. Натисніть кнопку **"+ Додати колір"**
4. Заповніть три поля:
   - **Назва кольору** (обов'язково) — наприклад: "Чорна обпалювання", "Світла", "Середня"
   - **Опис кольору** (опціонально) — деталі, наприклад: "Темна, интенсивна", "Світла, кисла"
   - **URL фото** (опціонально) — посилання на фото цього кольору:
     - Локальне: `images/products/coffee-dark.webp`
     - Зовнішнє: `https://example.com/photo.webp`

## Приклади конфігурацій

### Варіант 1: Товар з кількома ступенями обпалювання

```
Чорна обпалювання
Опис: Темна, інтенсивна, більше тіла
Фото: images/products/roast-dark.webp

Середня обпалювання
Опис: Збалансована, кисла, з фруктовими нотками
Фото: images/products/roast-medium.webp

Світла обпалювання
Опис: Яскрава кислотність, вишневі нотки
Фото: images/products/roast-light.webp
```

### Варіант 2: Декоративний товар з варіантами

```
Біла чашка
Опис: Класична біла
Фото: images/merch/cup-white.webp

Чорна чашка
Опис: Стильна чорна
Фото: images/merch/cup-black.webp
```

## Видалення варіанту

1. У розділі **"Варіанти кольорів"** натисніть кнопку **"✕ Видалити"** для потрібного варіанту
2. Варіант видалиться зі списку
3. Зберігаючи карточку, видалення зберігатиметься в базі даних

## Збереження

- Після редагування варіантів натисніть кнопку **"Зберегти"** внизу карточки
- Варіанти зберігаються у форматі JSON в базі даних
- На фронтенді варіанти відображатимуться разом з товаром (якщо інтегровано у продуктову сторінку)

## Дата-структура

Варіанти кольорів зберігаються як JSON масив:

```json
[
  {
    "name": "Чорна обпалювання",
    "description": "Темна, інтенсивна",
    "image_url": "images/products/roast-dark.webp"
  },
  {
    "name": "Світла обпалювання",
    "description": "Яскрава кислотність",
    "image_url": "images/products/roast-light.webp"
  }
]
```

## Поля

| Поле | Тип | Опис | Обов'язкове |
|------|-----|------|------------|
| `name` | string | Назва варіанту кольору | ✅ |
| `description` | string | Короткий опис або характеристика | ❌ |
| `image_url` | string | URL до фото варіанту (локальне або зовнішнє) | ❌ |

## Помилки та проблеми

### Коли варіанти не зберігаються
- Переконайтеся, що натиснули кнопку **"Зберегти"** для карточки
- Перевірте консоль браузера (F12 → Console) на помилки
- Переконайтеся, що у вас є права редагування каталогу (ваш email має бути в таблиці `catalog_admins`)

### Коли варіанти не відображаються на фронтенді
- Потребує інтеграції у продуктовій компоненті сайту
- Варіанти завжди зберігаються у базі даних, але фронтенд повинен їх рендерити

## Інтеграція з фронтендом

Варіанти кольорів доступні у об'єкті товару як `product.colorVariants` масив.

Приклад використання на сторінці товару:

```javascript
const product = { ... colorVariants: [...] };
if (product.colorVariants && product.colorVariants.length > 0) {
  // Рендерити сліди кольорів або таби з фотографіями
}
```

## Поєднання з іншими варіантами

Варіанти кольорів працюють незалежно від:
- Варіантів упаковки (250г, 1кг, мерч, поштучно, кастомні)
- Переоцінювання цін
- Текстових оверрайдів

Ви можете мати одночасно:
- Кілька варіантів упаковки (250г, 1кг, мерч)
- Кілька варіантів кольорів (світла, темна, середня)

Це комбінується у матрицю вибору для клієнта.
